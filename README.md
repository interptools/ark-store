# ARROYO Store POS

> Point of Sale system built with **Arroyo POS Engine** (MyStore POS)

## 🌐 Live App

**https://interptools.github.io/ark-store/**

## 📱 Install as App

1. Open **https://interptools.github.io/ark-store/** in Chrome (Android) or Safari (iPhone)
2. Tap **⋮ menu** → **Add to Home Screen**
3. Tap **Add** — your POS opens full screen like a native app
